Aprenda Flexbox

Flexbox é uma técnica de layout em CSS que permite criar layouts complexos de forma mais eficiente e flexível

Conceitos de Flexbox

Display Flex

O Display Flex é um modelo de layout do CSS que permite organizar e
alinhar elementos dentro de um contêiner de maneira dinâmica.

Justify Content

Controla o alinhamento dos items ao longo do eixo transversal.

Align items

Define o alinhamento padrão dos itens ao longo do eixo transversal do container.

Flex wrap

Permitem que os items se quebrem para a linha seguinte quando nao cabem no container.

Aplicacoes praticas

Layout Responsivo

O Layout Responsivo, ou Responsive Layout, é uma abordagem de design web que visa criar páginas que se adaptam a diferentes tamanhos de tela e dispositivos.

Alinhamento Perfeito

Centralizar elementos vertical e horizontalmente tornado simples.

Distruibuicao de espaco

O espaco disponivel e distribuido de forma equilibrada entre os itens, criando layouts harmoniosos.
